# BitChord Lite 1.0

Complete local-player foundation:
- Local MediaStore scan
- Album artwork
- Media3 playback service
- Background/media-session playback
- Play/pause and next/previous through Android media controls
- Search
- Favorites
- Home/Library/Search UI
- Shuffle/repeat can be controlled from the Android media session/client controls
- Modular source layer can be added for authorized online providers

Open in Android Studio, sync Gradle, then Build > Build APK(s).

Note: this project does not bypass Spotify/YouTube DRM, ads, authentication, or access controls.
